# Screenshots

Screenshots from Holo's Hanafuda, kept as evidence for its rules. The images stay on your machine and aren't in git, because they contain the game's art. Only this file is tracked.

To add evidence:

1. Save the image here, in `E:\projects\holokkrl\screenshots\`. Any file name works, though a descriptive one helps.
2. Say which round or rule it shows, and which screenshots belong together.
3. Each one then gets an entry in the [evidence log](../docs/HOLOS_HANAFUDA_CHECKLIST.md#evidence-log), and the [open items](../docs/HOLOS_HANAFUDA_CHECKLIST.md#open-items) it settles are closed. A score screen also becomes a test in `tests/test_score_screens.py`.

The most useful screens show the collected cards and the score together.
